Version 1.5.0 · macOS 14 or later · Apple Silicon · Free and open source

First launch: Lumina is signed but not notarized, so macOS blocks it once. Open System Settings → Privacy & Security, scroll to Security, and click Open Anyway. You only need this once. Later updates install themselves.

Features

Small app, sharp edges

Animations that actually play

Animated WebP, GIF and APNG play frame for frame, decoded through libwebp: around 186× faster than the system decoder on long animations.

No library, no import

Point it at folders or pick single images. Lumina reads them and forgets them again. No database.

Eight transitions

With adjustable display time and transition duration.

Slow camera move

An optional drift over each image, in three strengths.

Three scaling modes

Including fit with softly blurred edges, so nothing is cropped away.

Six languages

English, German, French, Italian, Spanish and Japanese. Lumina follows the system language.

Updates itself

New versions install themselves, verified against a built-in public key.

Private by default

No telemetry, no accounts, no network access beyond the update check, and that can be turned off.

Playback

Nothing cropped away

Fit with softly blurred edges: the whole image, edge to edge, on any screen.

Free, open source, and about as complicated as a slideshow app should be.
